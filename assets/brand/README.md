# Saudi Mark — Brand Character

## Official reference

- File: `saudi-mark-character-reference.jpg`
- Status: owner-provided brand reference
- Purpose: visual reference for the official Saudi Mark mascot/character in creative production, social content, merchandising, and future brand assets.

## Character description

The reference depicts a friendly white cat mascot wearing:

- A Saudi Mark blue cap with the brand logo.
- Dark blue protective goggles.
- A blue scarf.
- A blue-and-yellow water hose with a water splash.
- A Saudi Mark badge on the body.
- A clean blue, white, and dark-navy visual palette.

## Brand usage rules

1. Preserve the Saudi Mark logo on the cap and badge; do not redraw, distort, or replace it with generated text.
2. Keep the character friendly, clean, energetic, and service-oriented.
3. Prefer the established blue, white, dark-navy, and yellow accent palette.
4. The character may appear in motion graphics, social posts, app onboarding, service confirmations, gifts, uniforms, and campaign scenes.
5. Do not describe the character as an independently licensed third-party mascot; this file is an owner-provided reference.
6. Before external paid publication, confirm the final artwork and logo treatment with the brand owner.

## Creative direction

The mascot should communicate: **friendly mobile care, cleanliness, trust, water-conscious service, and a memorable Saudi Mark identity**.
